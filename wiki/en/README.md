# NTU Intercept Wiki

> Data snapshot: v1.0.0 · 2026-07-26

[中文 Wiki](../README.md) | [Repository](../../README_EN.md)

This is the English documentation entry point for the implemented game simulation. Historical names establish the setting; every performance value is game-scaled and must not be treated as real-world engineering or training data.

## Contents

- [Mechanics](MECHANICS/README.md): sensors, guidance, EW, flight, fleet AAW, damage, AAR, and telemetry.
- [Platforms](PLATFORMS/README.md): ships, fighters, strike aircraft, and AEW aircraft.
- [Weapons](WEAPONS/README.md): complete missile parameter catalog and weapon behavior.
- [Scenarios](SCENARIOS/README.md): default naval and joint-air presets.
- [Versioning](VERSIONING.md): documentation snapshot and implementation boundaries.

## Reading principle

The Wiki describes code behavior, not claimed real-world capability. A launch is proven by the owning entity's magazine, launcher state, physical departure, AAR event, and ACMI object. A shared track or assignment is never accepted as proof of launch.
