# Versioning and Data Boundaries

> v1.0.0 · 2026-07-26

[Wiki home](README.md) | [中文](../VERSIONING.md)

Every Wiki page identifies the implementation snapshot it describes. Historical platform and weapon names do not imply unscaled real-world performance. Source catalogs are authoritative for game values; documentation must be updated after catalog or behavior changes.

Claims about launches require physical entity evidence. Claims about network participation require activity/delivery evidence. Claims about visual features require rendered validation. A passing text search or HUD label is not sufficient evidence for any of these behaviors.
