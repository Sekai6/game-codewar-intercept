# Tu-16K Badger-G

> Data snapshot: v1.0.0 · 2026-07-26

双机反舰攻击编队，挂载 KSR-5。接近发射区后释放反舰弹并转向脱离；受截击时只做平台允许的防御机动和干扰弹投放，不使用 F-14 的战斗机策略。验证：`npm run verify:joint-air`。

## 任务与生存

编队依赖自身航迹、Tu-126/GCI 或海上目标指示建立远程攻击条件。KSR-5 必须从具体 Tu-16K 的挂点释放并消耗该机库存。发射后优先脱离；遭到 Phoenix/Sparrow 截击时可进行有限转弯、ECM 与诱饵投放，但大型轰炸机的滚转、过载和能量恢复不能达到战斗机水平。

联合场景中是否被四枚 Phoenix 击落不是固定脚本结果。应检查每枚导弹的中段更新、末端捕获、剩余能量、目标机动和 ECM 事件，再判断结果是否合理。

| ECM | 强度 0.68，烧穿距离 48 |
| 诱饵 | 箔条 42，热焰弹 18；4+2 连发，冷却 4.5 s |
| 挂载 | 中线 KSR-5 ×1；释放延迟 0.65 s，点火延迟 0.8 s |

平台无加力，临界迎角 13°、控制响应 1.4 s、发动机升转 7.2 s。其较高 RCS 使远程发现更容易，但 ECM、编队、目标航迹质量和截击时序仍会改变结果。

## C2、毁伤与遥测

苏联平台不接入 Link 16。它可接收 Tu-126/GCI、海上目标指示和舰队任务命令，但提示不等于 KSR-5 开火权。AAR 记录 GCI/海上提示、任务命令、齐射释放计划、具体发射飞机与 KSR-5 父子关系；损伤会限制推力、雷达、飞控和挂点。
