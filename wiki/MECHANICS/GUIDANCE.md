# 分阶段制导

> Data snapshot: v1.0.0 · 2026-07-26

导弹通常经历助推/动力段、惯性或数据链中段和末端导引头阶段。中段只能消费允许来源的航迹更新；进入搜索包线后，主动头进行概率捕获，半主动头要求持续照射，红外头根据目标热特征与视场捕获。视场、转弯上限、航迹年龄、ECM 和诱饵竞争会影响结果。

典型差异：AIM-54A 为舰载机中段更新后主动末制导；AIM-7F/R-27R 需要照射；AIM-9L/R-73 为红外；Harpoon、KSR-5、P-500 复用反舰末端搜索与掠海/跃升包线。验证：`npm run verify:air-guidance`、`npm run verify:anti-ship-guidance`。

## 两阶段/三阶段观察

中段导弹只知道最近一次允许的数据链或发射平台更新，因此目标转弯会造成预测误差；主动头开机后还要经过搜索器视场、捕获概率和抗干扰判断。半主动导弹在照射丢失时不能继续假装拥有精确目标真值。末端命中由交会几何、剩余能量、导弹转弯上限和引信距离共同结算。

“发射很远”不等于“必然命中”：远距离增加中段飞行时间和能量管理压力，目标机动、航迹老化、ECM 和末端搜索都会改变最终结果。
