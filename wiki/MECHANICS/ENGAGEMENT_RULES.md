# 交战规则与合法发射闭环

任何武器都必须依次通过：

`sensor track → engagement queue → fire-control solution → channel → ammunition → launcher/VLS → physical separation → guidance/seeker`

CEC、Link 11、Link 16、IRST 和 ESM 都只能提供信息或支持解算，不能直接生成导弹。远程测量过期、协方差过大、本舰通道不可用或目标分类不匹配时，火控必须拒绝并记录原因。

空空武器同样受平台火控、挂点、射界、距离和在途数量限制。AIM-54A/C 与 AIM-54X CEC 的中段能力不同，详见武器页面。
