# 毁伤与 AAR

> Data snapshot: v1.0.0 · 2026-07-26

命中结算使用战斗部、引信、接近距离和交会几何，并将结果写入平台子系统。飞机可损伤发动机、雷达、飞控和挂点，舰艇可出现分区毁伤、火灾、进水、发射器或火控退化。实体不会因 UI 文本瞬间消失；失控、坠海、击毁和 `leaker` 都应有事件链。

AAR/ACMI 只记录真实运行时实体和事件：owner、发射点、航迹、武器、诱饵、数据链和结果。导出器不得补造没有发生的发射。验证：`npm run verify:fleet-aar`、`npm run verify:acmi-export`。

## 复盘问题清单

1. 目标何时首次被哪一个传感器测量？当时航迹质量和不确定度是多少？
2. 哪艘舰接受了任务？它自己的弹药、通道和发射器是否可用？
3. 是否出现带 owner 和坐标的 `weapons-away`？导弹首次位置是否在物理挂点附近？
4. 导引头何时开机、捕获或丢失？期间是否存在 ECM、箔条或热焰弹实体？
5. 命中、脱靶、leaker、失控或坠海是否由同一条事件链解释？

这套问题清单是项目区别于“只看爆炸特效”的核心：每个视觉结果都应能回到可检查的状态和事件。
