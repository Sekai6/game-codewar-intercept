# 操作与 AAR

## 启动

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5173/`。场景面板用于选择平台、威胁、初始距离、图形质量、联合空战、舰队和数据链能力。

## 主要控制

- `AUTO FIRE`：启停旗舰自动舰载防空。
- `NAVAL FORCE`：启用独立多舰编队运行时。
- `SHIP ECM` / `SRBOC`：分别控制舰载干扰和物理诱饵释放。
- `CIWS`：控制近防自动交战。
- `TIME`：切换时间倍率。
- `END EXERCISE / AAR`：结束当前推演并打开复盘。

界面实际按钮文本是控制说明的权威来源；新增控制时应同时更新本页和浏览器验证。

## 镜头

- 数字键用于舰船、导弹、敌方平台、飞机和战术全景视角。
- `0` 切换舰队全景。
- `L` 跟随最近一次舰队实体发射的所属舰。
- `C` 切换电影镜头。
- 鼠标用于轨道旋转与缩放。

发射镜头 HUD 会显示舰名、舰号、发射架、发射单元和武器；它与当前手工选择的旗舰 HUD 是不同状态。

## AAR

AAR 记录平台状态、航迹、任务、数据链活动、实体发射、导弹、诱饵、毁伤和结果。敌方未确认的内部系统状态不进入战术 HUD，但可在诊断或复盘数据中保留。

舰队物理发射事件至少包含：

```text
shipId / launcherLabel / launchPoint / weapon / time
```

任务接受或队列预留不等于 `PHYSICAL LAUNCH`。

## Tacview ACMI

结束推演后可下载 `.acmi` 文件并导入 Tacview。导出内容包括：

- 舰艇、飞机、导弹和诱饵的独立对象与时序位置。
- 平台阵营、名称、航向、速度、高度和状态。
- 发射父对象、武器类型、目标和关键战斗事件。
- 舰队、数据链和毁伤相关文本事件。

验收 ACMI 时不能只搜索事件文本。必须同时核对：

1. 发射舰弹药是否减少。
2. 是否出现属于该舰的独立导弹对象。
3. 导弹首次坐标是否接近本舰物理发射点。
4. 是否存在对应 `PHYSICAL LAUNCH` 和 `weapons-away`。
5. 未发射舰的弹药是否保持不变。

## 性能注意

浏览器验收严格串行，每次只启动一个 Chromium renderer。不要并行运行多个 WebGPU、体积云、FFT 海洋或长时间联合场景截图任务。验证脚本默认使用固定短场景和 renderer 限制，避免过度占用 CPU/GPU。
