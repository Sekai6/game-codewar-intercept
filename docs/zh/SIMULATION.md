## 标准帧管线

主循环以固定仿真步长推进。高层顺序可概括为：

```text
实体运动与动力学
  -> 传感器扫描与测量
  -> 本地航迹更新与老化
  -> 数据链交换与舰队/空中态势融合
  -> 各实体 OODA 与任务规划
  -> 交战任务分配
  -> 本地武器授权、弹药和发射器状态机
  -> 导弹、诱饵、ECM、CIWS 与毁伤更新
  -> 视觉、HUD、AAR 与 ACMI 采样
```

`src/main.ts` 负责装配和调度；具体规则分别由 `src/air/`、`src/fleet/`、`src/ships/`、`src/ship-defense/` 与 `src/surface-combat.ts` 持有。

## 这套模拟的核心价值

系统有意把“感知、判断、执行、结果”分开。雷达探测不到就没有高质量航迹；有数据链 cue 也不代表本舰能开火；舰队分配任务也不代表发射器已经离架；看到爆炸更不能反向证明是哪艘舰命中。每一层都有独立状态和可验证事件，这让战斗结果可以在 HUD、AAR、ACMI、源码和测试之间互相核对。

相比只按距离触发命中，本项目能自然产生以下现象：掠海弹很晚才越过雷达地平线；附属舰因为本舰航迹不足而不发射；半主动导弹因照射中断脱靶；主动头在末端受 ECM/箔条竞争；受损飞机仍能脱离或最终坠海。这些现象不是预写动画，而是多个约束叠加的结果。

### 固定步长细节

每个仿真 tick 先积分实体运动，再执行传感器扫描和航迹老化；数据链按自身周期交换，随后各平台读取观察结果执行 OODA。交战分配不会跳过本舰验证，视觉和 AAR 只消费已经发生的运行时事件。`assigned` 表示任务已分配，`accepted` 表示射手接受，`weapons-away` 才是物理离架，之后进入 `assessing`、`resolved` 或 `leaker`。

## 实体与真值边界

舰船、飞机、导弹和诱饵实现通用可交战实体契约，保存真实位置、速度、特征和存活状态。传感器与 AI 不直接消费这些真值，而是使用包含估计位置、估计速度、质量、不确定度、分类、时间和来源的航迹。

真值只用于物理积分、传感器生成测量、碰撞/近炸结算和诊断。航迹不足、过期或未获得武器级授权时，武器不得发射。

## 传感器与航迹

- 探测距离按雷达标称能力、目标 RCS 四次方根、传感器健康和 ECM 修正。
- 雷达地平线同时考虑传感器高度和目标高度，掠海目标会显著压缩预警窗口。
- 雷达按自己的扫描周期刷新，不是连续真值圈。
- 成功探测生成带误差的测量；航迹会外推、衰减、增加不确定度并最终删除。
- 三维高度解算、解算质量和航迹年龄共同决定 `weaponQuality`。
- ESM 和数据链提示可帮助搜索或排序威胁，但不等同于本舰火控解算。

## 多舰防空闭环

舰队防空必须经过以下所有阶段：

```text
本舰有机雷达测量
  -> 本舰 weapon-quality 航迹
  -> 舰队态势图和 AAWC 威胁排序
  -> ForceEngagementAssignment
  -> 射手舰重新验证本地航迹、射程、弹药、通道和系统健康
  -> 本舰 ShipLauncherAdapter 预留 Mk 10/Mk 41 资源
  -> 发射器动画与状态机
  -> 物理离架
  -> 弹药确认扣减、weapons-away、导弹实体、AAR/ACMI
```

AAWC 会在具备独立武器级航迹的舰艇之间分配火力，已占用通道会降低该舰继续获配任务的效用。协调层不得直接调用导弹生成函数。

## 舰载发射器

Mk 10 模拟双臂装填、瞄准、抬升、离轨、复位和再装填。Mk 41 模拟独立单元、舱盖、银行冷却、热发射和物理发射点。排队和接受任务都不代表已经发射；只有离轨或热发射回调发生后才记录 `weapons-away`。

## 导引

- 舰空导弹：舰载中段引导或照射，末段按武器目录进入半主动或主动阶段。
- AIM-54A：发射机中段更新，进入主动头包线后自主捕获。
- AIM-7F 与 R-27R：持续半主动照射；照射中断会降低或终止制导。
- AIM-9L 与 R-73：红外捕获受方位、发动机状态、背景和热焰弹影响。
- AGM-84A、KSR-5、P-500 等反舰弹：按动力段、巡航高度、末端搜索、视场和 ECM/诱饵竞争推进。

## 飞行与空战 AI

空中平台使用三维速度积分。高级飞行路径进一步模拟空气密度、动压、推力、寄生/诱导阻力、迎角、滚转率、结构过载、失速与能量损失。

AI 分离为感知、战术规划、武器使用、威胁响应、飞行指令和控制律。推力具有 idle、cruise、military 与 afterburner 档位；加力影响推力、燃油、红外特征和可持续时间。机动意图必须经过控制律与包线保护，不能瞬间改变航向。

## 数据链与时代层

- NTU 基线使用 Link 11：NCS 轮询、容量限制、延迟、误差和质量折损。
- Link 11 网络航迹默认只提供 cue，不自动授予武器权限。
- Link 16 是独立、可选的较晚年代配置，不应用于苏联平台。
- 苏联侧使用独立 GCI、海上目标指示与齐射协调模型。
- CEC 仅在独立 `cec-enabled` 年代由 Long Beach、CG-57 与 E-2C 注册；Link 11/Link 16 本身不等同于 CEC。苏联平台不接入 CEC。

| 网络 | 游戏行为 | 不能做什么 |
|---|---|---|
| Link 11 | NCS 轮询、延迟、容量和质量折损，提供编队态势 cue | 不能自动授予发射权限 |
| Link 16 | 可选的较晚年代高质量共享，提供更快 cue | 不适用于苏联平台，也不是 CEC |
| 苏联 GCI/目标指示 | 独立的空情提示和齐射协调 | 不伪装成 NATO 数据链 |

更完整的实体清单和机制入口见 [Wiki](../../wiki/README.md)。

## 电子战与近防

ECM 影响雷达探测、导引头捕获和航迹质量，并存在烧穿距离。箔条和热焰弹是带位置、速度、寿命和信号强度的实体；雷达与红外导引分别竞争适用诱饵。舰艇 SRBOC 从对应舰体位置物理释放。CIWS 需要本舰局部航迹、炮位射界、转动时间、库存、冷却和系统健康。

## 毁伤与结算

毁伤通过标准实体接口进入平台。舰艇包含分区命中、火灾、进水和系统健康；飞机包含结构、发动机、雷达、飞控和武器系统损伤。击毁实体不会简单消失：飞机可能失控、解体或坠海，舰艇可持续燃烧和进水。

## 确定性

概率探测、导引头捕获、诱饵竞争和命中判定使用确定性随机源。同一场景、种子、设置和步长应产生可复现结果；浏览器帧率不应改变固定步长仿真的主要结果。
